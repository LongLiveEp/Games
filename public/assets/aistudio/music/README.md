# Саундтреки та фонова музика гри «В пошуках солі»

Завантажуйте ваші аудіофайли (`.mp3`, `.ogg`, `.wav`, `.m4a`) сюди:
`public/assets/aistudio/music/`

У коді гри (`_______bde2b5a0.html` / `js/sound.js`) вони будуть доступні за відносним шляхом:
`music/<назва_файлу>.mp3`
 або абсолютним шляхом:
`/assets/aistudio/music/<назва_файлу>.mp3`
